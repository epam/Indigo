# Conventions

> **Read when:** you are writing or reformatting Python in this repository.
> **Skip when:** the change is C++, Java, or configuration.

## Python code style

- Formatter: `black`, line length **79**
- Linters: `flake8`, `isort`, `mypy`, `pylint`
- `api/tests/integration` is excluded from flake8
